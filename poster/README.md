# FP3 Poster

Print-ready poster draft for the graduation project presentation.

## File

- `fp3-poster.html` — 70 × 100 cm portrait HTML/SVG poster.

## How to use

1. Open `poster/fp3-poster.html` in Chrome.
2. Replace placeholders:
   - Advisor name/photo
   - Group member names/roles/photos
   - Software screenshots
   - QR/demo/repository code
   - Department / team name
3. To export PDF:
   - Print → Save as PDF
   - Paper size: custom `70cm × 100cm`
   - Margins: none
   - Background graphics: enabled
4. To use in Figma:
   - Import the HTML with a plugin like `html.to.design`, or
   - Export as PDF/SVG/screenshot and place it in Figma.

## Required content covered

- Problem definition
- Project objectives
- Software model visuals / context diagram
- Software screenshots placeholders
- Project title
- Advisor name and photo placeholder
- Group member names, roles and photo placeholders
- 70 × 100 cm poster size
