- [ ] Hoca Endpoint'leri (GET /api/professors, GET /api/professors/:id)
- [ ] Öğrenci Endpoint'leri (GET /api/students, GET /api/students/:id)

- [ ] Yayın Yönetimi (CRUD /api/publications)

- [ ] Tag Endpoint'leri (GET /api/tags)
